# 🧶 Lephinton Crochets Website
A modern React-based website created for **Lephinton Crochets**, a handmade crochet fashion business showcasing unique crochet collections including bags, gowns, hats, and two-piece outfits.

## Project Overview
Lephinton Crochets is an online showcase platform designed to:
*   Present handmade crochet products professionally
*   Display collections in a clean gallery layout
*   Provide an engaging user experience 
*   Promote a small fashion business online

This project focuses on responsive layout, component-based design, and interactive UI styling using **React** and **CSS**.

## Features
*   **Gallery Section:** Displaying various crochet collections.
*   **Hover Overlay:** Showing product categories on interaction.
*   **Responsive Design:** Clean grid layout optimized for all devices.
*   **Smooth Animations:** Fluid image hover effects.
*   **Component-Based:** Built using reusable React components.
*   **Modern UI:** Simple, clean, and professional aesthetic.

## Collections Displayed
*   Bags
*   Gowns
*   Hats
*   Two-Piece Sets
Each collection appears with a hover overlay label inside the gallery.

## Tech Stack
*   **React.js**
*   **JavaScript (ES6+)**
*   **HTML**
*   **CSS**
